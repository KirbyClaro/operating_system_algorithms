PROJECT DESCRIPTION:
This project is an interactive GUI simulation suite for Operating System algorithms. It includes:

CPU Scheduling (FCFS, SJF, Priority, Round Robin) with Gantt Charts.

Memory Management (MFT, MVT) with visual Memory Maps.

Virtual Memory Replacement (FIFO, LRU, LFU, MFU, Optimal).

Disk Scheduling Management.

HOW TO RUN:
Option 1 (Easiest):
Simply double-click the "Run_Project.bat" file. This will automatically launch the main dashboard.

Option 2 (Terminal):

Open a terminal or command prompt in this folder.

Ensure Python is installed (Python 3.8+ recommended).

Run the command: python main_menu.py
